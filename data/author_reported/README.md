# Author-reported table transcriptions

The CSV files in this directory were transcribed from `Tables.docx` supplied by the author on 11 September 2026. They preserve the available values for reconciliation with the manuscript. They have **not** been regenerated from a processed AHBA matrix and have **not** been verified against full enrichment or gene-level output.

- `go_terms.csv`: all twenty entries in the supplied GO table. Names, categories, adjusted probabilities, and counts are retained as reported. GO identifiers and query/background lists were not supplied.
- `selected_genes.csv`: the nine visible entries in the supplied gene table. The original caption says ten. Its standardized difference definition is unresolved; the values must not be relabeled as log2 fold changes.

These files are not donor-level data, do not provide independent replication, and cannot substitute for the missing original expression matrix or executed analysis outputs. No donor values, missing tenth gene, or statistical significance values have been invented.
