# Manuscript reconciliation

The following items distinguish the original manuscript's claims from the evidence available in the supplied files and the legacy repository. The new workflow does not retrospectively establish that an analysis was performed.

1. **Design and participants.** The design uses a single reported imaging source and a reference postmortem atlas. It is not a systematic meta-analysis. The fMRI paper with DOI 10.1093/cercor/bhu158 enrolled multilingual participants without previous simultaneous-interpreting experience. AHBA donors were not sampled as interpreters.
2. **Coordinate provenance.** The manuscript specifies DLPFC −45, 36, 28 and caudate ±12, 15, 9. These coordinates were not located in the cited paper's peak tables. Reported caudate peaks there include right 12, 20, 6 and left −14, 0, 22; replacing the manuscript's targets would define a new analysis. Obtain the exact source, contrast, and selection rule.
3. **Spatial coverage.** A 2 mm spherical mask does not demonstrate that matched tissue lies within 2 mm of its center. Retain actual tissue mappings, distances, hemisphere labels, donor representation, and missing-region handling. A source population of six donors does not guarantee six donors in every ROI.
4. **Effect definition.** The legacy code computes the across-gene z score of regional mean differences. The manuscript describes a difference of normalized regional z scores and also invokes log2 fold change. These are different quantities. The new script names its donor-paired normalized difference explicitly and does not infer fold changes.
5. **Statistical unit.** If two regional profiles derive from the same donors, their dependence must be handled. Multiple tissue samples within a donor are not independent donors. The new implementation uses complete donor pairs; this is a prospective implementation choice, not proof that the original analysis did so.
6. **Gene sets.** Identify which results use a high-expression decile, low-expression decile, top 50, top 100, FDR-selected set, or the stated 43 genes with an additional fold-change threshold. These subsets can differ legitimately but must have separate exported lists.
7. **Enrichment.** Provide GO identifiers, annotation release, full query and background lists, overlap genes, correction settings, and raw result exports. Some figure labels differ from the table. Individual significance in two regions does not test a between-region difference in enrichment.
8. **Heatmap.** The supplied figure contains numerical annotations inconsistent with its colors, three columns but only two region labels, BRD1 versus DRD1 across materials, repeated GABRA1, and DAT1 alongside SLC6A3. Regenerate from validated data. Do not use the existing image as a source of missing numerical observations.
9. **Tables and duplicate figures.** The supplied gene table visibly contains nine entries although its caption says ten. The original Table 3 contains demographics rather than ROI coverage. Original Figures 3 and 4 contain the identical image. These are not independent analyses.
10. **Unprovided validation.** Outputs supporting claimed alleninf convergence, PCA, REVIGO reduction, and semantic clustering were not supplied. Those claims require their original code and results or must be removed.
11. **Scope of inference.** Regional atlas differences cannot demonstrate interpreting expertise, genetic aptitude, training-induced transcriptional change, fatigue prediction, or the efficacy of educational or pharmacological interventions.

The rewritten manuscript retains numerical values from the source tables as author-reported and flags unresolved items. New data preparation or analysis must be labeled as a new run, with its own provenance. It must not be tuned to reproduce the source table values.
